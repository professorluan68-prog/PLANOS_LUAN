## 1. SEQUÊNCIA REAL DAS ETAPAS (PADRÃO OPERACIONAL)

### AULA DE LEITURA (Sequência Fixa):
```
1. Retrieval Practice (Prática de Recuperação)
2. Disparo Inicial / Apresentação
3. Predição Guiada
4. Leitura Compartilhada
5. Conexão com Produção Textual
```

### AULA DE REDAÇÃO (Sequência Fixa):
```
1. Abertura e Retomada
2. Contextualização da Proposta
3. Planejamento do Texto
4. Fechamento e Encaminhamento
```

### AULA MISTA (Leitura + Produção):
```
1. Disparo Inicial: Retomada da Leitura
2. Contextualização da Proposta
3. Planejamento
4. Produção Textual
5. Encerramento da Aula
```

## 2. PADRÃO DE ESCRITA DA METODOLOGIA

### ESTRUTURA LINGUÍSTICA:
- **Linguagem**: Instrucional direta, imperativo predominante
- **Parágrafos**: Médios (3-5 linhas), organizados por blocos funcionais
- **Verbos do professor**: "Inicie", "Apresente", "Explique", "Oriente", "Solicite", "Finalize"
- **Ações dos alunos**: "Observem", "Reflitam", "Identifiquem", "Compartilhem"
- **Perguntas**: 2-4 por etapa, sempre em formato de lista com bullets
- **Objetivo pedagógico**: Sempre explícito ao final de cada etapa

### FORMATO PADRÃO:
```
[NOME DA ETAPA]

[Instrução inicial em 1-2 frases]

Perguntas orientadoras:
• "Pergunta 1"
• "Pergunta 2" 
• "Pergunta 3"

Objetivo: [explicação pedagógica em 1 frase]
```

## 3. PADRÃO OCULTO (REGRAS NÃO EXPLÍCITAS)

### REGRAS ESTRUTURAIS IDENTIFICADAS:
✔ **Sempre retoma conhecimento anterior** (primeira etapa obrigatória)
✔ **Sempre conecta leitura com produção** (etapa final obrigatória)
✔ **Mediação constante do professor** (nunca aula expositiva pura)
✔ **Perguntas como ferramenta pedagógica central** (mínimo 2 por etapa)
✔ **Progressão fixa**: Ativar → Explorar → Organizar → Produzir
✔ **Objetivo pedagógico explícito** em cada etapa
✔ **Registro no quadro** mencionado em 80% das etapas
✔ **Compartilhamento oral** sempre presente

### PADRÕES DE TRANSIÇÃO:
- Entre etapas: "Após essa breve explanação", "Finalize dizendo", "Encaminhe"
- Para perguntas: "Perguntas disparadoras", "Questões orientadoras"
- Para fechamento: "Objetivo:", "Reforce que", "Explique que"

## 4. COMO TRATAR REPETIÇÕES (REGRA DE OTIMIZAÇÃO)

### UNIFICAR QUANDO:
- **Retrieval Practice + Disparo Inicial**: Mesma função de ativação
- **Apresentação + Contextualização**: Mesmo objetivo introdutório
- **Fechamento + Encaminhamento**: Mesma função de síntese

### MANTER SEPARADO QUANDO:
- **Predição Guiada ≠ Leitura Compartilhada**: Funções distintas (antecipar vs. confirmar)
- **Planejamento ≠ Produção**: Etapas com produtos diferentes
- **Contextualização ≠ Retomada**: Focos temporais diferentes

### REGRA DE OTIMIZAÇÃO:
```
SE função_pedagógica == IGUAL:
    unificar_etapas()
SE função_pedagógica == DIFERENTE:
    manter_separado()
```

## 5. DIFERENÇAS POR TIPO DE AULA

### LEITURA (Foco: Compreensão e Interpretação)
- **Papel do professor**: Mediador de sentidos
- **Comportamento do aluno**: Participação oral ativa
- **Etapas específicas**: Predição Guiada, Leitura Compartilhada
- **Produto**: Hipóteses e interpretações

### PRODUÇÃO TEXTUAL (Foco: Planejamento e Escrita)
- **Papel do professor**: Orientador de processo
- **Comportamento do aluno**: Produção individual
- **Etapas específicas**: Planejamento, Produção Textual
- **Produto**: Projeto de texto e rascunho

### PLANEJAMENTO (Foco: Organização de Ideias)
- **Papel do professor**: Facilitador de estruturação
- **Comportamento do aluno**: Organização sistemática
- **Etapas específicas**: Contextualização, Planejamento
- **Produto**: Roteiro estruturado

### REVISÃO (Foco: Aperfeiçoamento)
- **Papel do professor**: Avaliador formativo
- **Comportamento do aluno**: Análise crítica
- **Etapas específicas**: Retomada, Reescrita
- **Produto**: Versão aprimorada

## 7. REGRAS DE QUALIDADE (VALIDAÇÃO)

### CHECKLIST OBRIGATÓRIO:
✔ **Sequência lógica**: Ativação → Exploração → Organização → Produção
✔ **Perguntas orientadoras**: Mínimo 2 por etapa, máximo 4
✔ **Ação do professor**: Verbo imperativo em cada instrução
✔ **Participação do aluno**: Ação específica definida
✔ **Conexão leitura-escrita**: Presente em todas as aulas
✔ **Objetivo pedagógico**: Explícito ao final de cada etapa
✔ **Registro/compartilhamento**: Mencionado em pelo menos 80% das etapas

### VALIDAÇÃO TÉCNICA:
```python
def validar_metodologia(aula):
    checks = {
        'tem_sequencia_logica': verificar_progressao(aula),
        'tem_perguntas_orientadoras': contar_perguntas(aula) >= 2,
        'tem_acao_professor': verificar_verbos_imperativos(aula),
        'tem_participacao_aluno': verificar_acoes_aluno(aula),
        'conecta_leitura_escrita': verificar_conexao(aula),
        'tem_objetivos_explicitos': verificar_objetivos(aula),
        'evita_etapas_soltas': verificar_coesao(aula)
    }
    return all(checks.values())
```

### CRITÉRIOS DE REJEIÇÃO:
❌ Etapas sem objetivo pedagógico
❌ Ausência de perguntas orientadoras
❌ Falta de conexão entre leitura e escrita
❌ Sequência não progressiva
❌ Linguagem não instrucional
❌ Ausência de mediação docente
